# DOMTRIK — Landing Page

Десктопная вёрстка лендинга по макету Figma `DOMTRIK | Landing Page` (`node-id=1-506`).

Стек: HTML5, CSS3 (Flexbox / Grid), нативный JS, методология БЭМ.

## Запуск

```bash
npx serve .
```

Или просто откройте `index.html` в браузере.

## Структура

```
.
├── index.html
├── css/style.css
├── js/main.js
└── assets/
    ├── fonts/     Vela Sans (400/500/600/700/800)
    ├── icons/     SVG-иконки и декоративные окружности
    └── img/       фотографии и карта
```

## Принятые решения

- Базовая ширина — 1920px (`--layout-width`), контейнер 1560px (`--container-width`),
  боковые поля 180px (`--container-offset`). До согласования десктопа у `body` стоит
  `min-width: 1920px` — при адаптиве это ограничение снимается.
- Цвета вынесены в CSS-переменные и соответствуют переменным Figma:
  `--color-dark: #292E3A`, `--color-white: #FFFFFF`, `--color-orange: #FF510F`, `--color-gray: #F4F4F5`.
  Дополнительно из макета: `--color-num: #D5D5D8`, `--color-border-soft: #FFB599`, `--color-muted: #7F838B`.
- Разный кегль внутри строки набран через `<span>`, без `scaleX`; дробные значения из макета
  округлены до целых px.
- `.markup-card` и `.max-widget` спозиционированы абсолютно по координатам макета.
  Если виджет MAX должен «прилипать» к экрану, замените у `.max-widget`
  `position: absolute` на `position: fixed` и задайте `right` / `bottom`.
- Карточки FAQ свёрстаны ссылками. Судя по архиву состояний, это не аккордеон:
  каждая карточка открывает модальное окно. Сами окна ещё не сделаны.
- `text-box-trim` / `text-box-edge` используются там, где в макете включён trim по capheight
  (числа в блоках «выгодно», номера причин, карточка наценки). В браузерах без поддержки
  свойства блок станет выше на несколько пикселей.

## Что осталось

1. Заменить заглушку постера видео, если для блока «О компании» будет реальный ролик.
2. Проверить подписи в «Хитах продаж»: у карточек «ОЛИВИЯ (голубой)» и «САВАННА (оранж)»
   цвет в подписи расходится с тем, что видно на фото. Названия и цены взяты из макета,
   фотографии — из выгрузки, сверить нужно по товарной базе.
3. Модальные окна: шесть для FAQ, отдельное «Оставить заявку» и галерея сертификатов.
   Состояния лежат в `assets/domtrik_visuals.zip`, тексты пока только картинками.
4. Адаптив — делается после согласования десктопа.
